# Historical simulation input snapshots

The original six files are byte-for-byte copies from public commit `331272ebe5a86248322fc13ee0fb5e6f4b31fe10`. Four additional frozen inputs (the estimator, simulation pipeline, Edge HTML and Edge JavaScript) are copied from public commit `9fd79199baf804e2886133e345887b41fd07719c`. Their SHA-256 digests match the original plan. The remaining restored file, `src/instrumentzero/web/app.js`, is shared with `examples/acquisition-acceptance-v0.2/source-snapshot/app.js`. Every snapshot is checked against the unchanged historical simulation plan before use. The replay is a mixed historical-input overlay on the current checkout, not an exact checkout of the historical commit. Existing simulation plans and receipts remain unchanged.
