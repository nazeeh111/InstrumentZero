# Changelog

## 0.2.0 — 2026-10-26

Public calibrated-recording validation: paired PTB sound-level surfaces, microphone pressure-sensitivity calibration metadata, retained ADC recordings and source checksums. Reproduces the published 1,089-position comparison with its physical limits explicit.

Recorded adaptive stiffness replay reveals only existing measurements after setting selection, then checks held-out reference observations. Exact selection ties a conventional endpoint protocol; adding data can worsen reference error. Standalone replay/calibrated packages preserve original data, code and notices.

Added 600 controlled acoustic cases and 18 shared-production acquisition checks. Fixed stale camera/microphone callbacks, out-of-frame marker tracking and delayed audio import/capture cancellation. No new physical measurements or hardware-calibration certificates are claimed.

## 0.1.0 — 2026-10-26

First public research preview: bounded stiffness/acoustic compiler, local Lab, calibrated inference, model checks, proposed cost-aware observations, CLI/Python interfaces, exact-data exports, offline Phyphox response validation, authentic fixtures and a 5,400-trial study.

The exact design method remains default. Learning did not establish practical value over its cheap teacher. Recorded evidence and synthetic benchmarks are distinct. Real camera/microphone acceptance and independently calibrated webcam stiffness remain unverified; source uncertainty and model limits are explicit.
