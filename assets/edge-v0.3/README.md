# InstrumentZero Edge preview assets

`instrumentzero-edge-walkthrough.mp4` is a silent, edited screenshot walkthrough of the actual independently installed interface. It shows synthetic Mount A and Mount B, a rejected signal, simulated disconnect/recovery, measured framed-transfer comparisons and the architecture. It is not a continuous recording, physical experiment or latency measurement.

Edit `walkthrough.json` and rerender with `render_walkthrough.py --work NEW_FOLDER --output NEW_MASTER.mp4`. Use an available font via `--font` when not on macOS. Every shot uses retained actual screenshots or the source-driven comparison figure. `architecture.svg` and `docs/edge/architecture.mmd` are editable architecture sources. The bar figure is regenerated from retained confirmation records with `scripts/summarize_edge.py`.

Desktop and 390-pixel mobile screenshots show the current workspace. Browser file-save observation timed out; the exact displayed export URL was fetched and independently recomputed instead. No hardware, microphone or camera was activated for these assets.
