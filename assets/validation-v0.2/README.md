# Recorded-validation walkthrough

Unaltered JPEG screenshots of the actual current-source Lab: selection of an existing source setting, revelation of its measured response, a held-out reference check, and the source-calibrated PTB comparison. Screens were captured through the browser at 1280×720. The rendered movie is silent and approximately 20 seconds; it is a screenshot walkthrough, not a new live physical experiment. Source data are independently attributed in the repository and evidence exports.

`bash render.sh` uses local FFmpeg with no overwrite. Use a new filename to revise the video and preserve the last valid render. The timeline and original screenshots are the editable source. No paid API, generated scientific footage, voice clone or fabricated physical result was used.
