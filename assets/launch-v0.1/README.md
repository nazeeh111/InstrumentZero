# Actual Lab walkthrough

Five unmodified 1280×720 screenshots of the working local Lab, captured 2026-10-26 through the browser:

1. Question and synthetic control result.
2. Compiled human-supervised procedure.
3. Fitted model, residuals and proposed next measurement.
4. Authentic CC0 recorded-audio analysis with uncertainty caveats.
5. Authentic CC BY stiffness data and an unreliable-model diagnosis.

`bash render.sh` produces a 20-second, silent H.264 walkthrough using local FFmpeg. The shots are editable through `timeline.txt` and the original JPEGs one directory above. New renders require a new filename; the script refuses overwrite. This is a screenshot walkthrough, not a live screen recording or new physical experiment. No narration or scientific footage is fabricated. Read docs/LAUNCH.md and the source data attribution.
